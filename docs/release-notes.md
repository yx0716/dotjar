- 捕捞改在后台进行：点击后页面不再等待，已有内容照常可看、可收下；完整生成的新卡片逐颗出现，标为「临时结果」，整轮完成后才可收下。刷新网页会接回原任务，不会重捞；旧版 CLI 不支持流式输出时，等完整结果。
- 首页减负：只显示时间、事情名称和星数，点开一件事再看你与 agent 各做了什么、存疑点和全部相关星星。成长反馈默认显示两条，其余可展开，展开收起不改已读状态。
- 新增 `dotjar uninstall`：先列出要做的事，确认后取消登录自启、停止后台服务，删除托管程序、`~/.local/bin/dotjar` 和 npx 缓存里的 dotjar；记录、设置和笔记保留。加 `--purge` 会把数据目录一起移到废纸篓；设在数据目录外的笔记目录始终不动。「应用程序」里的 dotjar 和安装包记录需要管理员权限，清单最后列出要你自己执行的命令。
- 检查和下载更新支持代理：依次使用 `HTTPS_PROXY` 环境变量、macOS 系统代理，最后直连；网络失败时说明主机、线路和错误码。只支持 HTTP(S) 代理。
- 从 0.4.x 升级到本版这一次，下载仍由旧版程序直连 GitHub。网络必须经代理时，若更新失败，可让代理软件接管全部流量（如 TUN / 增强模式）后再点「更新并重启」；升级完成后，之后的更新会走代理（「更新并重启」需要 Node.js 22.21+ 或 24+ 才能经代理下载）。
- 同一份数据由另一份 dotjar 程序或旧版服务占用时，不再接管，会提示从原入口停止；`install-managed` 新增 `--version` 和 `--entry-dir`。
- 已有托管版可在网页中检查更新并升级，无需卸载。
