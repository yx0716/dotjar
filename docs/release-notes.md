- 新增 macOS 双击安装包：自带 Node.js，安装后从「应用程序」打开 dotjar，首次初始化无需另行下载程序；已有托管安装和记录继续保留。
- 提供 Apple 芯片（arm64）和 Intel（x64）两种安装包，采用深蓝、四角星和衬线字的品牌视觉。
- 新增「捕捞记录与消耗」：查看每次尝试的引擎/模型、耗时、结果及可获取的参考费用或 token 用量。失败和重试分别记录；旧记录不补算，缺失用量显示不可获取。
- 参考费用不是额外订阅扣费，不换算成套餐百分比；账号剩余额度和定时捕捞尚未实现。
- 保留 0.4.1 对托管后台启动误报的修复。已有托管版可在网页中检查更新并升级，无需卸载。

安装包说明：文件名带 `unsigned-test` 的 .pkg 是未公证测试版，尚无 Apple Developer ID 签名及公证，macOS 可能拦截。Ed25519 签名更新包与 Apple 公证是不同机制。Apple 芯片安装路径已做运行验证；Intel 安装包完成构建，原生运行仍需验证。
