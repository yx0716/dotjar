# 捕捞记录与消耗

状态：开发分支已实现，尚未发布。日期：2026-11-11。

页面底部显示最近一次捕捞的消耗；点击打开「捕捞记录与消耗」。记录按正在查看的**材料日期**筛选，每行另外显示真实调用时间。补捞过去某天时，记录归在那一天。每次尝试单独保存，重试不覆盖失败记录；界面最多显示所选日期最近 100 次，并提示总次数。

## 显示口径

- Claude CLI：读取最终 result 的 `usage` 和 `total_cost_usd`，优先显示「参考费用约 $…」。这是客户端估算，不是服务商账单，也不表示订阅用户额外扣了钱。[官方说明](https://code.claude.com/docs/en/agent-sdk/cost-tracking)
- Codex CLI：探测 `exec --help` 是否支持 `--json`，读取这一轮最终 `turn.completed.usage`，正文仍从 `-o` 文件读取。重复终止事件取最后一个快照，不重复累加；旧 CLI 没有这项能力时仍可捕捞，用量显示不可获取。[官方事件示例](https://learn.chatgpt.com/docs/non-interactive-mode)
- OpenAI 兼容接口：读取 `usage.prompt_tokens`、`completion_tokens` 及缓存/推理细分；兼容接口缺字段时保留未知，不套用统一价格表。
- 输入总数已包含缓存部分，输出总数已包含服务商计入输出的推理部分，细分不再与总量相加。Claude 的非缓存输入、缓存读、缓存写合并为输入总数，必需字段缺失时总数未知。
- 没返回统计就显示「消耗暂不可获取」，不当作 0。收到统计后先落盘，再解析星星；即使输出格式错误，已知消耗也保留。中断、超时或取消时可能拿不到最终用量，会提示统计不完整。

## 保存与范围

记录保存于 `<dataDir>/runs/<UUID>.json`，默认 `~/.dotjar/runs/`。原子替换、文件权限 0600。只保存时间、目标日期、引擎/模型、程序版本、状态、新增星数和允许的数值用量字段；不保存密钥、对话、模型正文、原始 CLI 日志或账号余额。旧数据不补算；旧版仍可读取原有日台账，`costUsd` 兼容字段继续保留，但不拿它假装逐次记录。

网页、Electron、CLI 共用记录链路；网页和 Electron 通过同一 session 接口读取。多日捕捞每天单独记录。记录写入沿用更新期间的写入门控，升级回滚不抹掉已经发生的消费记录。

本次没有实现账号剩余额度、credits 适配器、套餐百分比换算、每日汇总、导出/自动清理、定时捕捞或跨进程捕捞互斥。已有进程间同时发起的调用分别记录，但本功能不负责阻止它们。

## 验证

使用隔离目录和模拟后端验证三类计量语义、缓存不重复计数、未知与零、失败仍有消耗、取消、异常退出、旧 CLI 降级、JSON 分块及重复事件、HTTP 鉴权和历史记录保留。浏览器使用合成数据检查入口与弹窗，不消耗真实模型额度。尚未用真实付费模型、Windows/Linux 或打包 Electron 做端到端验证。
